Planilha Google Sheets

Passo a passo no Google Sheets:

  1. Crie uma nova Planilha no seu Google Drive e abra-a. (Não precisa criar abas nem preencher nada)
  2. No menu, clique em Extensões > Apps Script.
  3. Apague o código de lá e cole este script abaixo: 
    function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var data = JSON.parse(e.postData.contents);
  if (data.action === "pre_fill") {
    for (var i = 0; i < data.rows.length; i++) { sheet.appendRow(data.rows[i]); }
    return ContentService.createTextOutput(JSON.stringify({"status": "success"})).setMimeType(ContentService.MimeType.JSON);
  }
  if (data.action === "update") {
    var values = sheet.getDataRange().getValues();
    var updated = false;
    for (var i = 0; i < values.length; i++) {
      if (String(values[i][1]).trim() === String(data.rm).trim() && String(values[i][6]).trim() === String(data.script_title).trim()) {
        sheet.getRange(i + 1, 1, 1, data.row.length).setValues([data.row]);
        updated = true; break;
      }
    }
    if (!updated) sheet.appendRow(data.row);
    return ContentService.createTextOutput(JSON.stringify({"status": "success", "updated": updated})).setMimeType(ContentService.MimeType.JSON);
  }
}
function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var data = sheet.getDataRange().getValues();
  var students = [];
  for (var i = 1; i < data.length; i++) {
    students.push({"rm": String(data[i][1]).trim(), "nome": String(data[i][2]).trim(), "numero": String(data[i][3]).trim(), "script_title": String(data[i][6]).trim()});
  }
  return ContentService.createTextOutput(JSON.stringify({"students": students})).setMimeType(ContentService.MimeType.JSON);
}
  4. Clique em Implantar > Nova implantação (Se for a primeira vez). Selecione App da Web, coloque acesso para "Qualquer pessoa" e clique em Implantar. Copie a URL!
  5. Se você está ATUALIZANDO um código existente: clique em Implantar > Gerenciar implantações. Edite (lápis) a implantação atual, mude a "Versão" para "Nova versão" e clique em Implantar.

Configuração da sua IA

Como obter a chave do Gemini (Recomendado - Gratuito):
1. Acesse o Google AI Studio.
2. Faça login com sua conta Google.
3. Clique no botão Create API key, crie uma chave em um novo projeto e copie o código gerado.
Como obter a chave do Groq (Super Rápido e Gratuito):
1. Acesse o Console do Groq.
2. Faça login.
3. Clique em Create API Key e copie o código gerado.
Como obter a chave da OpenAI:
1. Acesse a Plataforma OpenAI.
2. Faça login e insira saldo na conta (exige cartão de crédito).
3. Clique em Create new secret key e copie o código gerado.
Como obter a chave do xAI (Grok):
1. Acesse o Console do xAI.
2. Faça login e configure o faturamento (Billing).
3. Vá na seção API Keys, gere uma nova chave e copie o código gerado.
